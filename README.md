# Person Lab

Person Lab 是一个个人开发实验室，用于收集、整理和记录自己常用的组件、功能和业务模块。遇到一个值得保留的实现时，可以把它和相关经验放在这里，方便以后查阅、复用和继续改进。

## 计划收录的内容

- **组件与交互**：例如一个按钮在默认、悬停、聚焦、按下、禁用和加载状态下的表现。
- **独立功能**：例如一个完整的虚拟列表，记录可视区域渲染、滚动行为和长列表场景下的取舍。
- **业务模块**：例如一个完整的登录模块，涵盖表单校验、提交反馈、会话管理和退出登录。

每个条目可以按需记录它解决的问题、适用场景、关键行为和实现中的取舍。小到一个交互细节，大到一套完整流程，都可以独立收录。

## 当前状态

仓库已在本地初始化 Git，尚未关联远程仓库。组件、功能和模块将随实际需求逐步收录。
